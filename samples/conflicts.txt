====================================================================
一、配对冲突样例（列尺为 1-based，0-based 见说明）
====================================================================
标记约定： ⚠⟦…⟧ = 交叉/未配对点；fix = 自动补齐后的平衡文本

--- 样例 1 ---
原文   : （外层 [ 中层 ） 交叉 ]
列尺   :
                  111111
         123456789012345
冲突   : [行1 列10] 符号「）」与挡路符号 列5「[」 交叉
mark   : （外层 [ 中层 ⚠⟦）⟧ 交叉 ]
fix    : （外层 [ 中层 ]）[ 交叉 ]

--- 样例 2 ---
原文   : 《书名〈小节》收尾〉
列尺   :
                  1
         1234567890
冲突   : [行1 列7] 符号「》」与挡路符号 列4「〈」 交叉
mark   : 《书名〈小节⚠⟦》⟧收尾〉
fix    : 《书名〈小节〉》〈收尾〉

--- 样例 3 ---
原文   : “他说 ‘你好 ” 微笑 ’
列尺   :
                  11111
         12345678901234
冲突   : [行1 列9] 符号「”」与挡路符号 列5「‘」 交叉
mark   : “他说 ‘你好 ⚠⟦”⟧ 微笑 ’
fix    : “他说 ‘你好 ’”‘ 微笑 ’

--- 样例 4 ---
原文   : （a [ b { c ] d } e ）
列尺   :
                  11111111112
         12345678901234567890
冲突   : [行1 列12] 符号「]」与挡路符号 列8「{」 交叉
mark   : （a [ b { c ⚠⟦]⟧ d } e ）
fix    : （a [ b { c }]{ d } e ）
