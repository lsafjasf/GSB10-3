== 1. 多音字候选列表（含优先级依据）==
「行」候选：
  1. xíng   (现代汉语语料读音频率第 1 位；词表例证：行走)
  2. háng   (现代汉语语料读音频率第 2 位；词表例证：银行)
「长」候选：
  1. cháng  (现代汉语语料读音频率第 1 位；词表例证：长江)
  2. zhǎng  (现代汉语语料读音频率第 2 位；词表例证：长大)
「重」候选：
  1. zhòng  (现代汉语语料读音频率第 1 位；词表例证：重量、载重)
  2. chóng  (现代汉语语料读音频率第 2 位；词表例证：重复)
「乐」候选：
  1. lè     (现代汉语语料读音频率第 1 位；词表例证：快乐)
  2. yuè    (现代汉语语料读音频率第 2 位；词表例证：音乐)
「差」候选：
  1. chà    (现代汉语语料读音频率第 1 位；词表例证：差不多)
  2. chā    (现代汉语语料读音频率第 2 位)
  3. chāi   (现代汉语语料读音频率第 3 位；词表例证：出差)
  4. cī     (现代汉语语料读音频率第 4 位)
「着」候选：
  1. zhe    (现代汉语语料读音频率第 1 位)
  2. zhuó   (现代汉语语料读音频率第 2 位)
  3. zháo   (现代汉语语料读音频率第 3 位)
  4. zhāo   (现代汉语语料读音频率第 4 位)

== 2. 词组优先 vs 单字默认 ==
银行   词组模式: yín háng       单字模式: yín xíng
行走   词组模式: xíng zǒu       单字模式: xíng zǒu
长大   词组模式: zhǎng dà       单字模式: cháng dà
长江   词组模式: cháng jiāng    单字模式: cháng jiāng
重量   词组模式: zhòng liàng    单字模式: zhòng liàng
重复   词组模式: chóng fù       单字模式: zhòng fù
音乐   词组模式: yīn yuè        单字模式: yīn lè
快乐   词组模式: kuài lè        单字模式: kuài lè

== 3. 带声调 / 不带声调 ==
原文:   中国人民银行
带调:   zhōng guó rén mín yín háng
不带调: zhong guo ren min yin hang
数字调: zhong1 guo2 ren2 min2 yin2 hang2

== 4. 逐字候选（heteronym）==
银行 -> [['yín'], ['háng']]
行走 -> [['xíng'], ['zǒu']]

== 5. 定音依据（explain）==
  他 -> tā     单字默认音（语料频率第 1 位）
  在 -> zài    单字默认音（语料频率第 1 位）
  银 -> yín    命中词组「银行」规则
  行 -> háng   命中词组「银行」规则
  行 -> xíng   命中词组「行走」规则
  走 -> zǒu    命中词组「行走」规则
