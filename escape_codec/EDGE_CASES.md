# 边界用例清单

以下用例全部在 `tests/test_escape.py` 与 `roundtrip_fuzz.py` 中自动化覆盖。

## 结构性边界

| 用例 | 输入（线路字节） | 期望 |
|---|---|---|
| 空文档 | `b""` | `[[b""]]`（一条记录一个空字段） |
| 空记录 | `b"\n"` | `[[b""]]` |
| 单空字段 | `b"\n"` 编码侧 `encode_record([b""])` | 往返一致 |
| 连续空字段 | `b"|\n"` | `[[b"", b""]]` |
| 末尾无换行 | `b"a|b"` | `[[b"a", b"b"]]` |
| 多条空记录 | `b"\n\n\n"` | 3 条各含一个空字段的记录 |
| 零条记录编码 | `encode([])` | 拒绝（与空文档歧义），抛 `ValueError` |

## 字段内容边界

| 用例 | 说明 |
|---|---|
| 字段全是分隔符 | `b"||||"` → `b"\\|\\|\\|\\|"`，往返一致 |
| 字段全是换行 | `b"\n\n\n"` → `b"\\n\\n\\n"` |
| 字段全是反斜杠 | `b"\\\\"` → `b"\\\\\\\\"` |
| 嵌套转义 | 原始文本 `\|`，编码为 `\\\|`，解码先还原 `\\` 再处理 `\|` |
| 三重嵌套 | 原始 `\\`（2 字节）→ 编码 `\\\\`（4 字节） |
| 内容形似转义序列 | 原始文本 `\x41`（4 字节）→ 编码 `\\x41`，不会被二次解释 |
| 全字节表 | `bytes(range(256))` 逐字节往返 |
| 超长字段 | 4 KiB 随机字段（fuzz 中）/ 100 KB 重复字段（单测） |
| 超多字段 | 200 个字段的单条记录 |
| 多字节 UTF-8 | 原样透传，不做任何文本层解释 |
| NUL 字节 | 原样透传（编码侧不转义，解码侧 `\0`/`\x00`/`\000` 三种写法均可读） |

## 转义写法边界（解码）

| 用例 | 行为 |
|---|---|
| `\xHH` 恰好 2 位 | 合法，大小写 hex 均可 |
| `\x414`（超长） | **报错**：overlong，不允许静默截断 |
| `\x4` / `\x`（截断） | **报错**：truncated |
| `\xzz`（非法 hex） | **报错**：invalid hex digit |
| `\uHHHH` / `\UHHHHHHHH` | 按码点解析后编码为 UTF-8 |
| `\U00110000` / 代理区 | **报错**：invalid code point |
| `\0` `\07` `\012` `\377` | 八进制 1~3 位，值 ≤ 255 |
| `\400`（八进制溢出） | **报错**：exceeds byte range |
| `\012` vs `\0`+`12` | 优先级：八进制（更长匹配）优先于简单 `\0` |
| `\q` 等未知转义 | **报错**：unknown escape sequence |
| 行尾悬空 `\` | **报错**：dangling backslash，不猜测补全 |
| 混合写法同字段 | `\x41\102\u0043Z` → `ABCZ` |

## 错误定位边界

| 用例 | 期望位置 |
|---|---|
| 第 1 行出错 | line 1，列号 = 反斜杠字节列 |
| 多行文档第 N 行出错 | line N，列号按该行字节计 |
| 出错位置在字段中间 | 列号精确指向 `\`，不是字段起点 |
