# CDC 变更流分发与顺序保证

纯 Python 3 标准库实现，无第三方依赖。

## 文件

- `cdc.py` — 库：变更日志、主键分区分发、并行消费、位点持久化、全局重排
- `test_cdc.py` — 自测（unittest，7 个用例）
- `demo.py` — 端到端演示（含重排样例与位点记录样例输出）

## 运行

```bash
cd cdc
python3 -m unittest -v test_cdc   # 自测
python3 demo.py                   # 演示
```

## 设计要点

- **位点（lsn）**：`ChangeLog` 为每条变更分配全局单调递增 lsn，JSONL 落盘，重启不重置。
- **同键有序**：`Dispatcher` 按主键 blake2b 哈希到固定分区；分区数不变时同一主键永远同分区，
  每个分区单 worker 按日志顺序消费，因此同一主键严格按产生顺序投递。
- **跨键并行**：不同分区由独立线程并行处理，全局完成顺序允许乱序。
- **全局重排**：`ReorderBuffer` 缓存乱序到达的变更，只输出从指定位点起连续无缺口的前缀，
  可把并行结果重排回全局 lsn 顺序；重复位点自动丢弃。
- **位点确认**：`CheckpointStore` 按 `消费者组:分区` 记录已确认 lsn，原子写盘（tmp+rename），
  位点只进不退。按分区独立提交，避免单分区崩溃拖累/跳过分区。
- **重启重放**：`ParallelConsumer` 每次从磁盘位点 +1 重放日志。处理成功但位点未提交即崩溃时，
  该变更会被重复投递（at-least-once），业务侧以 lsn 作幂等键去重（见测试用例）。

## 自测覆盖

| 用例 | 断言 |
|---|---|
| 单键连续变更 | 投递序列 == 产生序列，乱序数 == 0 |
| 多键交错 | 每键严格有序且乱序数 == 0；并行完成顺序确实乱序；重排后 == 全局 lsn 顺序 |
| 重排缓冲缺口 | 缺口未补齐前不输出，补齐后连续输出，重复位点丢弃 |
| 消费者重启 | 崩溃分区位点回退，未确认变更重新投递且只重投该分区 |
| 重复投递 | 同 lsn 投递多遍，幂等表保证只生效一次 |
| 边界 | 空日志、单分区、分区数 > 变更数、位点不可回退、跨进程重读 |
| 分区稳定性 | 同主键恒定同分区；非法分区数报错 |
