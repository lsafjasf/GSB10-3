# 栅格路径规划（A* + 禁穿角 + 视线平滑）

纯 Python 3 标准库实现，无第三方依赖。

## 运行方式

```bash
# 全部自测（含可采纳性验证、穿角断言、平滑数据、边界用例）
python3 -m unittest planner.test_grid_planner -v

# 演示：边界场景路径数据 + 可采纳性摘要
python3 -m planner.demo
```

## 设计要点

- **移动模型**：八邻域，直走代价 1，斜走代价 √2。
- **启发函数**：octile distance，`h = √2·min(dx,dy) + |dx−dy|`，
  是无障碍时八邻域最短路的精确长度；障碍只会增加真实代价，
  故 `h ≤ g*` 恒成立（可采纳，A* 保证最优）。
- **禁穿角**：斜步 `(x,y)->(x+dx,y+dy)` 要求目标格自由，且两个共享边
  正交格不能同时阻挡（否则穿过障碍内角）。
- **平滑**：贪心视线取最远可达点；视线用 Amanatides–Woo 精确栅格遍历，
  过格点时套用与斜步一致的穿角规则，平滑不会引入非法移动。

## 文件

- `planner/grid_planner.py` — 库：`Grid / astar / octile_heuristic /
  smooth_path / line_of_sight / validate_path`
- `planner/test_grid_planner.py` — 14 个自测（unittest）
- `planner/demo.py` — 场景演示与数据输出

## 验证数据（本机运行结果）

- 可采纳性：30 张 20×20 随机图（障碍率 0.25）× 584 对采样，
  `h > g*` 违例 **0**；`h/g*` 最大 1.0000（开放图上取等，下界紧），
  平均 0.9042。真实代价 `g*` 由独立 Dijkstra 给出。
- 穿角：随机图全部有效路径经独立复核 `validate_path`，
  穿角移动数 **0**；双障碍夹角用例正确判无解/绕行。
- 平滑：随机图平均转折点 6.5 → 5.4，平均长度 35.350 → 34.830；
  开放地图平滑后收敛为直线段（长度 = 欧氏距离）。
- 边界用例：无解（整列墙隔离）、起点=终点（长度 0）、
  1 格窄通道（必经缝口）、完全开放地图、障碍上的起终点（抛错）。
