# 布局参考表（手算）

本文档给出布局规则与按规则手算的参考表。`tests/test_layout.py` 会把
`compute_layout` 的结果与同样的表逐项断言；表格可由
`python3 tools/dump_layout.py` 重新生成核对。

## 布局规则

1. 标量按自身宽度自然对齐：u8→1，u16→2，u32→4，u64→8。
2. 位域组按存储单元宽度对齐；组内位段按声明顺序紧凑排列
   （`lsb` 从 bit0 起，`msb` 从最高位起），不跨存储单元。
3. 定长数组按元素对齐，元素紧密排列，stride == 元素宽度
   （结构体元素的宽度已是其对齐的整数倍，天然成立）。
4. 结构体按声明顺序排布成员，成员偏移向上对齐到成员对齐，
   差值即前置填充；结构体对齐 = 成员最大对齐，末尾补齐到对齐的整数倍。
5. 填充字节取值不作规定：解码时原样记录、再编码时原样写回；
   用全新值编码时填 0。位域组内未分配的保留位同理。

## 手算过程

`Inner`：a(u32) 在 0；b(u8) 在 4；已用 5，对齐 4，末尾补齐 3，总宽 8。

`Packet`（成员最大对齐 4）：

- magic(u8)：offset 0，占 [0,1)
- flags(位域组 u8)：offset 1，占 [1,2)；version 占 bits 0..2，kind 占 bits 3..7
- count(u16)：对齐 2，offset 2，占 [2,4)
- tags(u8×3)：offset 4，占 [4,7)
- inner(Inner，对齐 4)：7 → 8 补 1 字节，offset 8，占 [8,16)
- tail(u8)：offset 16，占 [16,17)
- 末尾：17 → 20 补 3 字节，总宽 20
