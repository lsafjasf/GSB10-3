# 边界用例

均收录于 `tests/test_tableparse.py`，可用 `python3 -m unittest discover -s tests -v` 复现。

| 用例 | 输入特征 | 预期行为 |
|------|----------|----------|
| 单列 | 多行文本、行间无贯通空白带 | 推断为 1 列，不产生边界 |
| 不规则空白 | 列间空白 2~7 列不等、行内有前导空白 | 空白带聚簇为边界，正确切 3 列 |
| 空单元格 | 行中间/行首/行尾留空 | 对应位置为 `""`，行长度仍一致 |
| 全角字符 | 中文姓名、全角字母数字混排 | 按显示宽度（全角=2）对齐切分 |
| 分隔线 | `---+---`、`===+===` 行 | 自动跳过，不参与边界统计 |
| 跨列合并 | 某行内容连续穿越空白带 | 合并为 colspan 单元格，内容不丢失 |
| 跨行合并 | `^^` / `↑` / `〃` / `"` 标记 | 并入正上方锚点单元格（rowspan） |
| 连续跨行 | 同一列连续多个 `^^` | 向上找到真正锚点，rowspan 累加 |
| 悬空跨行标记 | 首行即 `^^` | 报错并指出行号（orphan_row_span） |
| 列数不一致 | 任意行数据（`validate()`） | 报告具体行号与偏差量（±n） |
| 跨列+跨行混合 | 同表同时存在两类合并 | 每行有效列数一致，spans 各自记录 |
