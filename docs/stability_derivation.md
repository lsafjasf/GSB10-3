# 稳定性条件推导（Von Neumann 分析）

方程：`u_t + a u_x = ν u_xx`（a ≥ 0, ν ≥ 0），均匀网格间距 `dx`，步长 `dt`。

无量纲数：

- Courant 数 `c = a·dt/dx`
- 扩散数 `r = ν·dt/dx²`

方法：将谐波解 `u_j^n = G^n e^{i k x_j}`（`θ = k·dx ∈ [0, 2π)`）代入差分格式，
得放大因子 `G(θ)`。Von Neumann 稳定判据：

```
max_θ |G(θ)| ≤ 1
```

记 `s = sin(θ/2)`，`sinθ = 2s·cos(θ/2)`。

---

## 1. FTCS（显式中心差分）

格式：

```
u_j^{n+1} = u_j^n − (c/2)(u_{j+1} − u_{j−1}) + r(u_{j+1} − 2u_j + u_{j−1})
```

代入谐波：

```
G(θ) = 1 − 4r s² − i c sinθ
|G|² = (1 − 4r s²)² + c² sin²θ
     = 1 − 4s²[ 2r(1 − 2r s²) − c²(1 − s²) ]
```

令 `y = s² ∈ [0,1]`，`|G|² = 1 − 4y·q(y)`，`q(y)` 为 y 的一次函数，
故 `|G|² ≤ 1 ∀y` 等价于两端点 `q(0) ≥ 0` 且 `q(1) ≥ 0`：

```
q(0) = 2r − c² ≥ 0        ⇒   c² ≤ 2r
q(1) = 2r(1 − 2r) ≥ 0     ⇒   r ≤ 1/2
```

**稳定条件与临界步长：**

```
r ≤ 1/2  且  c² ≤ 2r
dt ≤ min( dx²/(2ν), 2ν/a² )
```

推论：

- 纯扩散（a=0）：`dt ≤ dx²/(2ν)`，即经典的 `r ≤ 1/2`。
- 纯对流（ν=0）：`c² ≤ 0` 不可能 ⇒ **FTCS 对纯对流方程恒不稳定**。
- 对流扩散耦合时，第二个条件 `dt ≤ 2ν/a²` 与网格无关，
  加密网格不能消除它——这是 FTCS 用于对流主导问题的本质限制。

## 2. 迎风（上风）显式格式

```
u_j^{n+1} = u_j^n − c(u_j^n − u_{j−1}^n) + r(u_{j+1} − 2u_j + u_{j−1})
G(θ) = 1 − c − 4r s² + c e^{−iθ}
```

利用 `cosθ = 1 − 2s²` 整理实部，并记 `p = c + 2r`：

```
Re G = 1 − 2p s²,   Im G = −c sinθ
|G|² = (1 − 2p s²)² + 4c² s²(1 − s²)
     = 1 − 4(p − c²) y + 4(p² − c²) y²,   其中 y = s² ∈ [0,1]
```

`|G|² − 1 = 4y·g(y)`，`g(y) = (p² − c²)y − (p − c²)` 是 y 的一次函数，
故 `|G|² ≤ 1 ∀y∈[0,1]` 等价于 `g(0) ≤ 0` 且 `g(1) ≤ 0`：

```
g(0) ≤ 0  ⇔  p ≥ c²  即  c + 2r ≥ c²
g(1) ≤ 0  ⇔  p² ≤ p  ⇔  c + 2r ≤ 1   （p ≥ 0）
```

而 `c + 2r ≤ 1` 蕴含 `c ≤ 1`，从而 `c² ≤ c ≤ c + 2r`，第一个条件自动成立。
故充要稳定条件为

```
c + 2r ≤ 1
```

**临界步长：**

```
dt ≤ 1 / (a/dx + 2ν/dx²)
```

- 纯对流：`c ≤ 1`（CFL 条件），`dt ≤ dx/a`。
- 纯扩散：退化为 `r ≤ 1/2`，与 FTCS 相同。

## 3. Lax-Friedrichs（纯对流）

```
u_j^{n+1} = (u_{j+1} + u_{j−1})/2 − (c/2)(u_{j+1} − u_{j−1})
G(θ) = cosθ − i c sinθ
|G|² = cos²θ + c² sin²θ ≤ 1   ⇔   |c| ≤ 1
```

**临界步长：`dt ≤ dx/a`（CFL 条件）。**

## 4. Lax-Wendroff（纯对流）

```
u_j^{n+1} = u_j^n − (c/2)(u_{j+1} − u_{j−1}) + (c²/2)(u_{j+1} − 2u_j + u_{j−1})
G(θ) = 1 − 2c² s² − i c sinθ
|G|² = 1 − 4c²(1 − c²) s⁴ ≤ 1   ⇔   |c| ≤ 1
```

**临界步长：`dt ≤ dx/a`。** 二阶精度，`c²` 项为人工粘性，是稳定性的来源。

## 5. BTCS（后向欧拉隐式）

```
−(c/2 + r) u_{j−1}^{n+1} + (1 + 2r) u_j^{n+1} + (c/2 − r) u_{j+1}^{n+1} = u_j^n
G(θ) = 1 / (1 + 4r s² + i c sinθ)
|G|² = 1 / ( (1 + 4r s²)² + c² sin²θ ) ≤ 1   ∀c, r ≥ 0
```

**无条件稳定。** 但精度仍受 `dt` 限制（时间一阶），大 `dt` 时误差大。

## 6. Crank-Nicolson

```
G(θ) = (1 − 2r s² − i (c/2) sinθ) / (1 + 2r s² + i (c/2) sinθ)
|G|² = [ (1 − 2r s²)² + (c/2)² sin²θ ] / [ (1 + 2r s²)² + (c/2)² sin²θ ] ≤ 1
```

**无条件稳定**，时间二阶。注意纯对流（r=0）时 `|G| ≡ 1`（零耗散），
间断解会产生非物理振荡，但对光滑解精度最好。

## 汇总表

| 格式 | 类型 | 稳定条件 | 临界步长 dt_crit |
| --- | --- | --- | --- |
| FTCS | 显式 | r ≤ 1/2 且 c² ≤ 2r | min(dx²/(2ν), 2ν/a²) |
| 迎风 | 显式 | c + 2r ≤ 1 | 1/(a/dx + 2ν/dx²) |
| Lax-Friedrichs | 显式 | c ≤ 1 | dx/a |
| Lax-Wendroff | 显式 | c ≤ 1 | dx/a |
| BTCS | 隐式 | 无条件 | — |
| Crank-Nicolson | 隐式 | 无条件 | — |

## 边界条件的说明

Von Neumann 分析严格适用于周期边界（或纯初值问题）。
对 Dirichlet / Neumann 边界，内部格式的判据不变（边界只改变有限维矩阵的
少数行），本库用 Dirichlet 超临界实验（`demo.py` 第 4.1 节）验证了这一点：
r=0.6 时 40 步误差放大 4.3×10⁵ 倍，与周期情形理论值 `(4r−1)^40` 一致。
