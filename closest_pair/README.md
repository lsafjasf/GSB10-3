# 最近点对（closest pair of points）

Python 3 实现，仅用标准库（`math`、`random`、`time`、`unittest`）。

## 文件

- `closest_pair.py` — 库
  - `closest_pairs(points)`：分治，O(n log n)
  - `closest_pairs_bruteforce(points)`：暴力，O(n²)，对拍基准
- `test_closest_pair.py` — 21 个用例：边界用例 + 1600 组随机对拍（unittest）
- `benchmark.py` — 耗时基准

## 运行方式

```bash
python3 test_closest_pair.py   # 自测 + 对拍
python3 benchmark.py           # 耗时数据
```

库调用示例：

```python
from closest_pair import closest_pairs
d, pairs = closest_pairs([(0, 0), (1, 0), (10, 10), (11, 10)])
# d == 1.0
# pairs == [((0, 0), (1, 0)), ((10, 10), (11, 10))]
```

## 算法

经典分治（`closest_pair.py:80`）：

1. 点按 x 排序后递归切成左右两半（点带唯一 id，坐标重合也能正确切分）；
2. 两半各自求最小距离 `d`；
3. 只扫描距分割线水平距离 ≤ d 的带状区域，带内点按 y 排序，每个点只向
   后比较 y 差平方 ≤ d² 的常数个点（几何装箱论证，最坏常数个）；
4. 全程比较平方距离，只在最终开一次方。

输出全部并列点对：带状扫描用 `<= d` 而非 `< d`，距离相等时追加点对而不是
替换；跨带重复计入的点对在输出前去重。输出点对与列表整体均按坐标排序。

重合坐标按位置去重：n 个完全重合的点输出 1 个点对（距离 0），否则输出本身
就是 O(n²)，与库的复杂度保证冲突。点的"id 对"属于调用方语义。

边界约定：点数 < 2 返回 `(None, [])`。

## 对拍数据

随机点集上逐组比较分治与暴力的返回值（距离 + 全部点对集合），共 1600 组、
累计校验 14159 对最近点对，0 组不一致：

| 场景 | 组数 | 一致 |
|---|---:|---:|
| 均匀浮点坐标 (-1000, 1000) | 500 | 500 |
| 小范围整数 (0..8)²，强制大量重合/并列 | 500 | 500 |
| 共线点 | 300 | 300 |
| 极端量级 ±1e15 | 300 | 300 |

小范围整数场景下 200/200 组出现并列最小距离，验证"全部输出"。
另有 n=3000 的单组对拍（见 `test_closest_pair.py` 的 `test_larger_instance`）。

## 边界用例

在 `test_closest_pair.py` 中：

- 点数 0、1：返回 `(None, [])`；点数 2：唯一点对
- 全部重合（1000 个相同点）：距离 0，去重后 1 个点对
- 部分重合：最近距离 0
- 共线：水平、垂直、对角线（斜向间距 √5）
- 极端坐标：±1e15 混排；1e-12 微小间距与 1e15 混排（验证浮点分辨力）
- 3×3 单位网格：12 条边全部为并列最近点对
