# spatial_query — 三角形网格空间查询（BVH）

纯 Python 3 标准库实现，无任何第三方依赖。用 BVH（层次包围盒）加速
射线查询与 AABB 包围盒查询，支持物体移动后的增量更新（refit），
并附带与全量暴力检测的对拍自测和耗时基准。

## 运行方式

```bash
# 对拍自测（35 项检查，BVH vs 暴力逐条比对）
python3 -m spatial_query.tests          # 或 python3 spatial_query/tests.py

# 耗时基准（默认 20000 三角形 / 2000 射线 / 2000 包围盒 / 2000 次移动）
python3 -m spatial_query.benchmark      # 或 python3 spatial_query/benchmark.py
python3 -m spatial_query.benchmark 50000 1000 1000 2000   # 自定义规模
```

## 目录结构

- `spatial_query/geometry.py` — 几何基元：Möller–Trumbore 射线-三角形求交、
  slab 射线-AABB、SAT（15 轴）AABB-三角形相交。BVH 与暴力共用同一套判定函数。
- `spatial_query/bvh.py` — BVH 索引：12-bin SAH 建树、栈式迭代查询、
  `move_triangle()` 增量 refit、`rebuild()` 整体重建。
- `spatial_query/brute_force.py` — 全量暴力参考实现（对拍基准）。
- `spatial_query/scenes.py` — 场景/查询生成器（固定随机种子，可复现）。
- `spatial_query/tests.py` — 对拍自测入口。
- `spatial_query/benchmark.py` — 耗时基准入口。
- `spatial_query/results/` — 实测输出存档（对拍结果、两组规模的耗时数据）。

## 设计要点

- **建树**：沿质心包围盒最长轴做 12-bin SAH 切分，叶子最多 4 个三角形；
  节点存扁平数组，查询零递归。
- **射线查询**：`ray_query(orig, dir)` 返回按 t 升序的全部命中 `(id, t)`；
  `nearest_hit()` 取最近命中。方向向量无需归一化。
- **包围盒查询**：`box_query(bmin, bmax)` 返回与盒相交的三角形 id 集合；
  查询盒完全包住某节点时整棵子树直接收集，跳过逐三角形 SAT。
- **增量更新**：`move_triangle(slot, verts)` 重算所在叶子包围盒并沿父链
  refit（O(深度)，拓扑不变）；移动很多后可 `rebuild()` 按新分布整体重建。
- **一致性保证**：BVH 与暴力共用 `geometry.py` 中同一套相交判定，
  命中列表按 `(t, id)` 确定性排序，因此结果可逐条比对。

## 耗时对比（benchmark.py，Python 3.12.3 实测）

20000 三角形 / 2000 射线 / 2000 包围盒 / 2000 次移动：

| 项目 | BVH | 全量暴力 | 加速比 |
|---|---|---|---|
| 建树 | 266 ms（一次性） | 0（无索引） | — |
| 射线查询 | 78 µs/条 | 9701 µs/条 | **124x** |
| 包围盒查询 | 242 µs/次 | 13727 µs/次 | **57x** |
| 移动更新 | **8.1 µs/次**（增量 refit） | 267 ms/次（整体重建） | **~33000x** |

50000 三角形 / 1000 射线 / 1000 包围盒 / 2000 次移动：

| 项目 | BVH | 全量暴力 | 加速比 |
|---|---|---|---|
| 建树 | 828 ms（一次性） | 0 | — |
| 射线查询 | 199 µs/条 | 23021 µs/条 | **116x** |
| 包围盒查询 | 618 µs/次 | 34406 µs/次 | **56x** |
| 移动更新 | **12.7 µs/次**（增量 refit） | 862 ms/次（整体重建） | **~68000x** |

说明：

- 建树是一次性成本（约 13–17 µs/三角形），摊到后续每次查询上即可忽略；
  暴力检测每条射线都要扫全部三角形，规模越大差距越大。
- 增量 refit 只沿父链更新 O(log n) 个包围盒，比整体重建快 3–4 个数量级，
  适合“少量物体频繁移动”的场景；若一次移动了大部分物体，应改用 `rebuild()`。
- 每次基准运行前后都会自动做对拍校验（`结果逐条一致` / `post-update differential OK`）。

原始输出见 `spatial_query/results/benchmark_20k.txt` 与 `benchmark_50k.txt`。

## 边界用例覆盖

- 空网格：查询返回空，不崩溃。
- 单三角形：命中、落空、包含、相离。
- 大量重叠：2000 个共面三角形，射线一次命中全部且顺序确定。
- 退化三角形：三点共线、顶点重合（射线判定自动排除，包围盒判定正常）。
- 查询完全落空：场景外射线/包围盒、场景内背向射线。
- 数值边界：起点在三角形平面上、盒与三角形共面接触、射线擦边过顶点。
- 增量更新：单个/批量移动、旋转、远距离瞬移、更新后整体重建。
