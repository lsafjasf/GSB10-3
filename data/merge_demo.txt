合并演示：输入 -> 合并结果（优先级：数值越小越高）

## 单段
  输入  10.1.0.0/24            priority=10
  输出  10.1.0.0/24            priority=10

## 相邻（对齐，聚合成单个 CIDR）
  输入  10.1.0.0/24            priority=10
  输入  10.1.1.0/24            priority=10
  输出  10.1.0.0/23            priority=10

## 相邻（非对齐，最少 CIDR 覆盖）
  输入  10.2.0.0/24            priority=5
  输入  10.2.1.0/24            priority=5
  输入  10.2.2.0/24            priority=5
  输出  10.2.0.0/23            priority=5
  输出  10.2.2.0/24            priority=5

## 完全相同（去重，取最高优先级）
  输入  10.3.0.0/24            priority=8
  输入  10.3.0.0/24            priority=3
  输出  10.3.0.0/24            priority=3

## 包含（小段被吸收，保留组内最高优先级）
  输入  10.4.0.0/16            priority=20
  输入  10.4.5.0/24            priority=7
  输出  10.4.0.0/16            priority=7

## 跨版本混合（v4/v6 分别合并，互不混算）
  输入  10.5.0.0/24            priority=1
  输入  2001:db8::/64          priority=2
  输入  2001:db8:0:1::/64      priority=2
  输出  10.5.0.0/24            priority=1
  输出  2001:db8::/63          priority=2

## 链式相邻（多段连成一片）
  输入  10.6.0.0/24            priority=4
  输入  10.6.1.0/24            priority=4
  输入  10.6.2.0/24            priority=4
  输入  10.6.3.0/24            priority=4
  输出  10.6.0.0/22            priority=4
